How to read these results

A number without a subject, denominator and scope is not a finding. The records separate static structure, execution and limits instead of collapsing them into one label.

Pinned object

Each summary names the repository and commit observed; it does not extrapolate to a moving branch.

Visible scope

Results are limited to the files, tests or layers contracted for that run.

Falsifiability

Where applicable, controls and conditions that would change the verdict are declared.

Publishable nulls

“Zero in scope” is a result; it does not certify the entire system as defect-free.

Boundary: these samples are structural and CI analyses, not a general security certification. The PyTorch report here concerns test reachability, not dependency cycles; there is no Scrapy audit in this published selection yet.
